# 공학용 계산기 (Scientific Calculator)

브라우저에서 바로 실행되는 단일 HTML 공학용 계산기입니다. 설치나 빌드 없이 `index.html`만 열면 동작합니다.

## 기능
- 사칙연산, 괄호, 거듭제곱(xʸ, x², x³), 제곱근(√, ∛), 1/x, %, mod
- 삼각함수(sin·cos·tan)와 역함수, 쌍곡선 함수, DEG/RAD 전환
- ln, log, log₂, eˣ, 10ˣ
- n!(소수는 감마함수), nPr, nCr, 난수, π, e, 지수 표기(EXP)
- 2nd 버튼으로 보조 기능 전환
- 입력 중 결과 미리보기, 괄호 자동 닫기, 암시적 곱셈(`2π`, `3(4+1)`)
- Ans, 메모리(MC/MR/M+/M−), 계산 기록(브라우저에 저장)
- 키보드 입력 지원, 모바일 반응형

## 안전성
`eval`을 쓰지 않고 직접 구현한 재귀 하강 파서로 수식을 계산합니다.
